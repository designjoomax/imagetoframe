Update frame

Alternatif untuk update-frames.bat (cocok untuk Mac/Linux). Hasilnya sama.

  1. Pilih semua file .png dari folder assets/frame/.
  2. Klik Download frames.js & frames-data.js.
  3. Simpan kedua file ke folder js/ dan timpa yang lama.

    Nama file menentukan urutan dan nama: 1 Frame Joomax.png tampil sebagai "Frame Joomax" di urutan 1. Tanpa angka di depan, frame ditaruh paling akhir.
